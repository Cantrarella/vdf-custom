# 结果页布局优化（2026-10-03）

窗口较窄或放大界面时，查重结果页的状态分类、排序按钮和“更多筛选”会互相挤压，部分文字无法完整显示。展开的筛选选项也容易将标签与输入拆到不同的行。本批改动调整布局，保留现有筛选和文件操作行为。

## 改动内容

- **工具栏完整显示**：搜索、状态分类、排序和更多筛选根据可用宽度换行，避免横向裁切。
- **筛选区分组**：按排序、筛选条件、分组与选择、显示内容排列；标签与对应控件成组，相似度起止值放在一起，预览宽度独立成行。
- **短窗口保留结果空间**：筛选区高度随页面调整，选项通过内部滚动访问，避免完全挤占结果列表。
- **文件行更清晰**：状态和相似度标签移至文件名上方，允许换行，减少与比较参数重叠。保留原有最佳指标的字体与颜色差异。
- **勾选与操作含义明确**：增加常显勾选提示；删除菜单只包含回收站与永久删除，复制、移动和清理预演报告移到更多操作。底部摘要、按钮和提示按可用宽度排布。
- **设置说明更简洁**：精简中英文 pHash、组合模式、AI 匹配、AI 组件、AI 片段检测的说明，保留用途、开销、依赖与限制，仍然常显。

查重引擎、ViewModel 与文件操作命令未修改。本批继续维护英文和简体中文文案。

## 验证结果

- 全量 GUI headless 自动测试：**299 项通过，0 失败，0 跳过**。
- 新增检查覆盖中英文窄工具栏、150% 布局放大、短窗口结果列表、底部操作按钮边界和文件标签防重叠。
- Windows x64 自包含单文件发布成功。
- 检查了浅色与深色主题的实际 Skia 无头渲染图。
- 使用者运行新版后确认测试正常。

测试环境固定初始 100% 缩放，避免读取上次测试保存的缩放值而影响弹窗几何断言；AI 筛选控件的测试显式展开筛选面板。以上调整仅涉及测试环境，不改变真实用户的设置。

自动化的 150% 布局放大检查不等同于覆盖所有 Windows 系统 DPI 配置，也未穷举最大预览宽度与每种窗口尺寸的组合。
